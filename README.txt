Phoachum Learning Games v1

ไฟล์นี้เป็นเว็บเกมแยกจากระบบ NFC Attendance

ไฟล์สำคัญ:
- index.html : เว็บเกมทั้งหมด

วิธีทดลอง:
- ดับเบิลคลิก index.html เพื่อเปิดในเบราว์เซอร์

วิธีขึ้น Vercel:
1. สร้าง GitHub repository ใหม่ชื่อ phoachum-learning-games
2. อัปโหลด index.html
3. เข้า Vercel > Add New > Project
4. Import repository นี้
5. Framework Preset = Other
6. Build Command = เว้นว่าง
7. Output Directory = .
8. Deploy

เกม:
1. จับคู่ชิ้นงาน 3D กับภาพฉาย Front / Top / Right
2. ทายภาพฉายจากชิ้นงาน 3D

คะแนนสูงสุดบันทึกใน localStorage ของอุปกรณ์
